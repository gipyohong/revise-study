# LLM 미세조정 학습 메모 (연습용 예시 자료)

LoRA(Low-Rank Adaptation)는 기본 모델의 가중치 대부분을 고정하고, 작은 저랭크 행렬을 학습해 모델을 특정 작업에 맞게 조정하는 방법이다.

QLoRA는 양자화된 기본 모델을 활용하면서 LoRA 어댑터를 학습하는 방식이다. 기본 모델 가중치를 저비트로 보관해 학습 중 필요한 메모리를 줄이는 것이 핵심 장점이다.

RAG는 모델 파라미터를 바꾸는 대신 외부 문서를 검색해 프롬프트에 전달한다. 따라서 새 자료의 사실을 반영하려면 문서를 갱신하고 인덱스를 다시 만들 수 있다.
