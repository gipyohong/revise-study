# LangGraph 학습 메모 (연습용 예시 자료)

LangGraph에서 State는 그래프의 각 노드 사이에 전달되는 현재 실행의 상태 데이터다. 질문, 검색 결과, 중간 답변 등을 State에 넣어 노드 간에 공유할 수 있다.

Store는 실행을 넘어 재사용할 정보를 보관하기 위한 저장소다. State는 현재 실행의 데이터 전달에 초점을 두고, Store는 사용자별 선호나 누적 지식처럼 여러 실행에서 조회해야 하는 정보 저장에 사용한다.

Checkpoint는 그래프 실행 상태를 저장하고 재개하는 데 도움을 준다. Store와 Checkpoint의 역할은 구분해야 한다.
